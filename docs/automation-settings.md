# Automation Settings

## Environment

- Automation source: Cloud
- Local computer execution: Disabled
- Start in a new chat each run: Enabled
- Timezone: Asia/Seoul
- Schedule: Daily 08:40

## Shared Automation URL

https://chatgpt.com/scheduled?automationId=6ac338e041088190a0ba6695599cbfff&automationSource=cloud&share_dialog=true

## Reason for Cloud Execution

The task should run even when the local computer is turned off or unavailable. Cloud execution makes the routine more reliable for daily content operations.

## Reason for Starting in a New Chat

Each scheduled run starts from a clean context. This reduces the risk of unrelated previous chat context affecting the daily topic search.

Because the run starts fresh, the prompt itself includes key operating rules:

- Check recent content history.
- Avoid duplicate topics.
- Verify sources and publication dates.
- Do not publish externally without explicit approval.
- Flag insurance advertising compliance risks.
